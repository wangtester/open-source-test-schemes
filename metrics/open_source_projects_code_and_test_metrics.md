## 3. 统计洞察与质量工程特征分析

1. **测试代码占比分布**：
   * 顶级开源项目的测试代码占比普遍在 **25% ~ 48%** 之间。
   * 框架/编译类工具（FastAPI 47.1%、Vitest 45.8%、DeepSeek Harness 39.6%、Playwright 40.4%）的测试代码占比最高，几乎接近 1:1 的代码-测试配比。
2. **AI 开发开源项目的测试特征**：
   * 由 AI 驱动/自举开发的项目（如 OpenHands、LobeChat、Dify、Bolt.new）展现出极高的测试规范度，测试代码占比稳定在 **28% ~ 35%**。
   * 采用高度声明式的单测夹具与结构化 Mock，大幅降低了非确定性模型输出带来的维护成本。
